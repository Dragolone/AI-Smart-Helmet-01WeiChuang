# 10-17 安卓模拟器回归（补安卓列空着的行）

> 起因：负责人问「还有什么能跑的吗」。华为当时没连电脑，iPhone 锁着；不用人配合就能跑的，在安卓模拟器上跑了。
> 设备：Android 16 模拟器（Pixel 8，无声启动），10-16 打的开发包 + Metro（main 84637f4 起，加上本次修复），本地后端（短信是控制台假通道，求救不会发真短信）。
> 驱动：adb 点按 / 读界面树 / 截图；动画用系统录屏、按每秒 30 帧逐帧看。倒计时页一直在动时界面树导不出来，只能看截图、按坐标点。
> iOS 模拟器：开头跑了一行就停了——倒计时页的警报会从 Mac 扬声器放出来，负责人在用电脑。之后会响的用例只在安卓模拟器上跑。

## 结果

结果写在回归清单的「模拟器预检」列（不替代真机）：

- 求救：4.22、4.25、4.27、4.28、4.29、4.30 都过了；8.6 再看一遍。
- 没头盔时的三步指引：2.9.1–2.9.19 整节都跑了，2.9.17 发现叠字（已修）。
- 其它：1.5.4、2.8.12、2.8.13、2.8.14、2.8.15。

本地环境的替代做法：
- 没有真推送：「点通知」用同一条路由的深链代替；锁屏通知撤不撤没法验。
- 断 WebSocket：安卓模拟器的接口走 adb 端口转发，关模拟器网络断不掉。改为重启 adb 服务约 20 秒，代替飞行模式。

## 发现与处理

| 编号 | 现象 | 处理 |
|---|---|---|
| F13 | 两顶以上同时求救点「全部取消」：结果页顶上还挂着「XX：已取消，已切到下一单」。几单是一起取消的，这句话会误导。原因：取消请求逐单发、逐单回，第一单先结束时其余几单在缓存里还算进行中，自动切单逻辑就弹了提示 | **已修**：记下这次「全部」操作涉及的单号，这些单结束时不弹提示（有单测，修复前会失败） |
| F14 | 头盔在倒数中被解绑，结果页点「我还是需要帮助」：弹框写「找不到头盔」，接着写「求救请求已暂存，网络恢复后将自动发送」。服务端 404 重发也不会成功，补发队列也会直接丢掉，这句话是假的安慰。安全页的按住求救也是同样写法 | **已修**：404 / 403 / 400 这类重试没用的错误不进补发队列，提示改成「求救没有发出，也不会自动重发。需要帮助请直接拨打电话」；断网、超时照旧暂存（判定抽成 `services/relay-errors.ts`，补发队列和两个页面共用；有单测） |
| F15 | 三步指引换件时新旧内容叠几帧：主流程里状态标签先换成下一件（「已绑定」上叠「已开启」），下一件早已备齐（连着往下走）时整块正文叠 2 帧。10-16 iOS 的 F9 修过同类问题，这条路径没覆盖到。原因：代码假定「动画共享值比页面重画先到动画线程」，新架构下不成立，重画先到的那一两帧里新的那件按「停着」显示 | **已修**：新增「现在轮到第几件」共享值，和其它几个一起设；一件内容露不露面只看共享值，共享值到之前新的那件藏着、旧的那件照常显示。修后逐帧看不再叠（单测补了两种时序） |
| F16 | 换件那一下页面要重画、挂上下一件，模拟器上卡 1–4 帧：旧的那件按钮里的勾先消失，淡出被跳过。修 F15 之前同样有 | 性能问题，没改；要在真机正式包上看明不明显。若明显，可以提前把下一件挂好（F15 之后这样做是安全的） |
| F17 | 开发包偶发闪退（今天倒计时页切到结果页十几次，崩了 2 次）：React Native 新架构的断言 `Sealable.cpp:59 Attempt to mutate a sealed object`。原生调用栈是 Yoga 排版时对「按基线对齐」的文字算基线（`ParagraphShadowNode::baseline`），这一步改了已封存的文字节点。两次都发生在倒计时页底下的设备页正在重排时（其中一次正好是头盔被解绑、设备列表变了），设备页电量那一行用了基线对齐 | 没改。正式包里这条断言是关掉的，不会因此闪退，但开发包测试会被打断。规避办法：常重排的几行（设备页电量那行等，共 7 处用了基线对齐）改成不用基线对齐，要看设计；或留意 React Native 后续版本是否修了 |
| O1 | 指引在第三件时，从别的设备给这个账号加联系人：卡片不会自己打勾，要等下一次重拉联系人（切走再回来、或重新进页） | 观察。正常使用是在本机加联系人，加完返回会立刻刷新 |
| O2 | 从接口给账号绑上头盔后停在地图页，半分钟后地图页还写「还没有添加头盔」 | 观察。切回设备页会重拉，地图页自己不刷新 |
| O3 | 模拟器上的开发包是 10-16 凌晨打的，注册的链接前缀还是旧的 `app://`（#191 改成了 `lingyizhixing://`） | 测深链 / 视频预览深链参数前要重打开发包 |
