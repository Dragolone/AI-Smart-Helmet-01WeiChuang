### 地图（#227）

WebView 内容进程被系统回收后永久白屏 → 换新 WebView 并重推状态；头盔 Marker 只能移动不能收起（换到没定位的头盔仍显示上一顶的位置）；看历史行程时每来一个实时点就把视野弹回整趟；`reload()` 后不再回调 onReady（轨迹 / 标记 / 在线状态丢失）；跨月后行程列表漏掉新月份；已加载的轨迹后台刷新失败一次就整页报错、回放还在跑；REST 旧点盖掉更新的 WS 点（头盔往回跳）；换头盔时上一顶的轨迹接到新头盔位置画出长线；回放读数速度没过滤飞点；地图未就绪时命令队列无上限；离开地图页回放不停；「查看该时刻」查询失败被当成不在任何一趟；抽屉抓手 / 进度条读屏不可用；重开行程列表把翻过的页全部重拉。

### 设备设置 / 指引 / 绑定（#228）

音量乐观值被别的项的回执清掉、PUT 失败卡在「应用中」；头盔没上报过音量时把 80 显示成头盔确认值、取消高音量确认拿 80 去「还原」；音量回执在头盔回来后还说「头盔离线」；头盔自己上报改过值后「已生效」还挂着；雷达距离连点 + 发同一个值；绑定页被求救页盖住时相机还在扫码；音量拖到一半被打断状态卡住；iOS 读屏听不到回执变化；加载中被当成「从没上报」；指引第二件拒过通知后去设置打开也不打勾；电量图 ≤20% 就红（与首页三档不一致）。

### 对讲 / 视频预览（#229）

进房途中退出登录 / 超时 / 换频道，晚到的凭证照样进房开麦；iOS 不检查麦克风权限、没有 onError（拒了也能「说话」，对端听不到）；进房失败 / 超时不停采集；被服务器移出 / 房间解散时一声不响回到列表；成员格和按住说话读屏不可用；通话中频道从列表消失，小条和标题跟着没了；进入有人的房间连响一串「有人进来」并重拉 N 次成员；「耳机」其实是听筒；iOS 拒绝本地网络后视频预览只报通用错误；提示音缓存文件被清后整个进程没有提示音。

### 账号 / 基础设施（#231）

语言 / 外观 / 当前头盔在锁屏被 BLE 拉起时读不出钥匙串、整个进程定死成默认（当前头盔影响 App 内求救记在谁名下）；联系人拉失败显示成「尚未添加」、可以重复添加；WS 被 4401 拒后每秒重连并刷新 token；刷新暂时失败时页面显示「手机号或密码不正确」；换号后登录页预填旧号；登录后连接横幅立刻闪出；短信读秒按页面不按号码、被限频不读秒；注销后本机留着上行队列文件和按账号存的条目；安全记录后面几页不随刷新更新；注册 / 找回密码缺验证码和新密码的自动填充提示；密码长度按 UTF-16 算与服务端不一致；选头像失败弹原生英文报错。
