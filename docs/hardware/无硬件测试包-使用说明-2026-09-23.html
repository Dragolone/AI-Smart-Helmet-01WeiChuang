1.0 这个包做什么

在电脑上起一路和头盔相同约定的 RTSP：端口 8554、路径 /ch0、H.264、1280×720、30 fps、TCP。画面是彩条加时间戳，用来把播放页做完，不需要板子。

2.0 电脑怎么开测试流

  1. 安装 ffmpeg：winget install Gyan.FFmpeg，或从 ffmpeg.org 下载并把 bin 加入 PATH。
  2. 电脑和手机连同一个普通 Wi-Fi（家里路由即可）。
  3. 关掉 VPN。
  4. 双击 启动测试流.bat。窗口会打印本机 IP 和完整 URL。
  5. 先用本机 VLC：媒体 → 打开网络串流 → 粘贴 rtsp://127.0.0.1:8554/ch0，选项加 :rtsp-tcp。看到彩条说明源是好的。

ffmpeg 监听一次只接一个客户端。用完 VLC 先关掉，再开 APP。黑窗口不要关，关了流就停。

3.0 APP 怎么播

播放代码和真机完全一样，只改主机：

环境地址
本测试包rtsp://<电脑局域网IP>:8554/ch0
真机头盔rtsp://192.168.176.1:8554/ch0
  1. 强制 RTSP over TCP。
  2. H.264 硬解，铺到 16:9 画面。
  3. 进后台停播，回前台重新 PLAY。

电脑 VLC 能出画、APP 不能：查 TCP、手机和电脑是否同一网段、Android 是否把流量绑到蜂窝网。电脑也不能：先把本包的流拉起来，不要先改协议。

5.0 BLE 怎么测

本包不广播 Helmet-*。没有头盔时，用 BLE十六进制对照.txt 做组包 / 解包 / ACK 的单元测试。字段以《AI智能头盔BLE通信协议手册》v0.6 为准。
