# 主界面与次级界面文案冗余复查

日期：2026-10-08。版本：`helmet-ui-worktree`，`feat/home-redesign`。

本轮沿设备、地图、对讲、安全、我的五个主入口检查相邻页面及弹层。重点是同一路径上重复解释同一规则、标题与正文复述结果、入口与表单重复教学。修改限于文案及其展示，不增加功能，不修改操作回调、权限判断、接口或业务状态。

## 已处理的重复

| 路径／场景 | 冗余情况 | 最终处理 |
| --- | --- | --- |
| 对讲空态 → 创建／加入 | 正文再次解释已经由两个按钮表达的创建与加入动作 | 空态只保留头盔音频连接前提；创建、加入由按钮说明 |
| 对讲 → 创建或加入弹层 → 表单 | 入口副标题提前重复下一步的命名、邀请码格式 | 删除两个操作的副标题；频道名称与 6 位格式在相应表单中说明 |
| 频道详情 → 退出确认 | 两处都解释“退出后需邀请码重新加入” | 频道详情仅显示人数和上限；退出后果只在确认框中说明 |
| 紧急联系人 → 添加联系人 | 列表已说明求救短信用途，添加页又解释联系人是短信接收人 | 添加页直接呈现姓名、手机号、关系与保存，不复述用途 |
| 地图 → 选择头盔 | 顶部和底部分别解释地图选择与当前头盔的关系 | 合并为顶部一段：“仅切换地图显示。当前头盔及手动求救关联需在「设备」页更换。” |
| 绑定 → 成功卡片 | 标题“绑定成功”后，正文再次显示“头盔已绑定至本账号” | 常规成功状态删除复述正文；配置未完成时只说明安全设置入口 |
| 安全 → 安全设置 | “头盔切换”“流程体验”各自只有一个选项，重复下面行标题的含义 | 删除两处无补充信息的分组标题；保留切换提醒说明和演练不发送通知的说明 |
| SOS 倒计时 | 上方解释倒计时结束通知联系人，环内又解释秒后发送 SOS | 环内仅显示数字与“秒”；完整规则保留在上方，并跟随系统字号 |
| SOS 结果 | “已取消”“短信发送失败”等标题在正文再次复述 | 正文改为补充后果或下一步，如“未发送联系人通知，求救记录已保留”“请直接拨打电话求助” |

简体、繁体、英文同步处理；删除了 8 个已无调用的重复文案键，调整 9 个保留文案键。

## 顺带纠正的操作语义

- 对讲页“离开”改为“结束通话”，与次级页面的“退出频道”区分。前者保留频道成员身份，后者移除成员身份。回调不变。
- 绑定成功页按钮原文“前往安全设置”实际调用 `router.dismissAll()`，没有打开安全设置。现统一为“完成”；配置未完成时，正文说明“请到「安全」→「设置」完善求救通知配置”。按钮行为不变。

## 保留说明的理由

- 连接、通知权限、离线设置结果等随状态变化的提示，仍保留在需要作出决定的页面。
- 持续通话的首次确认与当前麦克风状态说明分别用于操作确认和使用中判断，保留。
- 退出频道、解除绑定、注销账号等确认框保留操作后果。
- 页面标题、表单字段、联系人数量及无障碍标签用于确认当前对象或操作，不按文字相同一律删除。
