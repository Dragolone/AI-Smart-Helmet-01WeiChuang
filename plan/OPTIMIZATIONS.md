# 上线后优化清单

> 不卡上线、上线后有空再做的改进（负责人 10-21 晚要求设这一份，第一条是「自适应开屏」）。
> 每行写清现状为什么能接受、怎么做、出处；做了的划掉并写 PR 号。新发现的「可改进 / 观察项」往这里加。
> 与上线清单的关系：`plan/LAUNCH_CHECKLIST.md` 第六节「不卡上线、上线后再补」是商务 / 第三方类（厂商推送、Critical Alerts 等），这里是产品和代码类。
